# Установка Chess Hint на iPhone с Windows (без Mac)

Схема: **GitHub Actions** (бесплатный облачный Mac) собирает приложение →
ты скачиваешь `.ipa` → ставишь на телефон по проводу через **Sideloadly**.

---

## Шаг 1. Загрузить проект на GitHub

1. Зарегистрируйся на https://github.com (если аккаунта нет).
2. Создай новый репозиторий: кнопка **New repository** → имя `ChessHint` →
   выбери **Private** (не публикуй публично — в проекте исходники Stockfish под GPL,
   для приватного репо это ок) → **Create**.
3. Залей проект. Проще всего через **GitHub Desktop** (https://desktop.github.com):
   - File → Add Local Repository → выбери папку `ChessHint`
   - Repository → Push.

   Либо через командную строку (замени `ТВОЙ_ЛОГИН`):
   ```bash
   cd "ChessHint"
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ChessHint.git
   git push -u origin main
   ```
   Появится окно входа GitHub — войди.

Репозиторий уже инициализирован, коммит сделан — пушить готово.

## Шаг 2. Дождаться сборки

1. Открой репозиторий на GitHub → вкладка **Actions**.
2. Там уже запустился workflow **Build iOS app**. Сборка занимает ~10–15 минут
   (компилируется Stockfish).
3. Когда появится зелёная галочка — открой запуск, внизу в **Artifacts**
   скачай **ChessHint-unsigned-ipa** (это zip с файлом `ChessHint.ipa`).

## Шаг 3. Установить на iPhone через Sideloadly

1. Скачай и поставь **Sideloadly**: https://sideloadly.io (Windows-версия).
2. Скачай и поставь **драйверы Apple** (нужны, чтобы Windows видела телефон):
   - iCloud для Windows: https://apps.apple.com/ru/app/icloud/id1302148179
   - iTunes (из Microsoft Store тоже подойдёт)
3. Распакуй `ChessHint.ipa` из скачанного zip.
4. Подключи iPhone кабелем → разблокируй → нажми «Доверять» если спросит.
5. Открой Sideloadly:
   - Перетащи `ChessHint.ipa` в окно
   - В поле **Apple ID** введи свой Apple ID (тот же, что на iPhone)
   - Нажми **Start** → введи пароль Apple ID (если запросит код 2FA — подтверди)
6. Подожди ~2 минуты. На iPhone: **Настройки → Основные → VPN и управление
   устройством** → найди свой Apple ID → **Доверять**.

Приложение появится на рабочем столе. Готово — открывай и жми «Подсказка».

---

## Нюансы бесплатного Apple ID

- Подпись живёт **7 дней**, потом приложение перестанет запускаться — просто
  повтори шаг 3 (данные в приложении сохранятся при переустановке тем же Apple ID).
- Лимит: 3 приложения от одного Apple ID одновременно.
- 99$ в год за Apple Developer нужен только если хочешь подпись на 1 год
  и публикацию в App Store.

## Если сборка упала

Открой лог в Actions (кликни на красный крест → упавший шаг) и пришли мне
последние ~30 строк ошибки — поправлю конфиг.

## Если Sideloadly не видит телефон

- Смени кабель/порт USB (нужен Data-кабель, не только зарядка)
- Проверь, что установлены iTunes + iCloud (шаг 2)
- На iPhone нажми «Доверять этому компьютеру»
